# ASMCode: Intel 8080 IDE

ASMCode - это современная, высокопроизводительная и легковесная среда разработки (IDE) на языке Rust с декларативным графическим интерфейсом на базе фреймворка Slint. Приложение создано специально для написания, статического анализа, компиляции и эмуляции программ на ассемблере микропроцессора Intel 8080 и операционной системы CP/M.

---

## Ключевые возможности

### 1. Двухслойный редактор кода
- **Живая подсветка синтаксиса**: мгновенное выделение токенов (мнемоники, регистры, директивы, метки, шестнадцатеричные числа, строковые литералы и комментарии) без задержек ввода.
- **Моноширинный курсивный шрифт**: встроенная поддержка `CaskaydiaCove NF SemiBold` с аккуратным курсивным начертанием.
- **Синхронизированный наклонный курсор**: плавное мигание (период 530 мс) с точным позиционированием символов и наклонной геометрией.
- **Поддержка масштабирования**: увеличение и уменьшение шрифта редактора через `Ctrl + Колесо мыши` или кнопки в панели управления.
- **История изменений**: полная поддержка отмены (`Ctrl+Z`) и повтора (`Ctrl+Y`) правок с сохранением позиции курсора.
- **Комментирование кода**: быстрое переключение строчных комментариев `;` по нажатию `Ctrl+/`.

### 2. Сборка и эмуляция CP/M
- **Компиляция в машинный код**: вызов ассемблера `asmx20.exe` для генерации исполняемых файлов CP/M формата `.COM`.
- **Запуск в эмуляторе**: прямая интеграция с `cpmemu.exe` для мгновенного выполнения `.COM` программ прямо из IDE с выводом результатов в нижний терминал.
- **Статическая валидация**: встроенный анализатор корректности инструкций, регистров и аргументов перед сборкой.
- **Защита от потери данных**: автоматическая валидация активного файла, предотвращающая перезапись исходников пустыми буферами при закрытии вкладок.

### 3. Интеллектуальный справочник и автодополнение
- **Интерактивная энциклопедия Intel 8080**: 60 документированных инструкций процессора. Для каждой команды указаны синтаксис, изменяемые флаги (Z, S, P, CY, AC), время выполнения в машинных тактах и размер в байтах.
- **Двуязычный интерфейс**: переключение языка подсказок и документации (Русский / Английский) на лету.
- **Контекстные подсказки**: всплывающее окно автодополнения по `Ctrl+Пробел` с возможностью быстрого перехода по стрелкам `Up`/`Down` и вставки по `Enter`/`Tab`.
- **Детектор меток (Labels Outline)**: автоматический парсинг меток и директив `EQU` в реальном времени с номерами строк и быстрой навигацией.

### 4. Проводник файлов и контекстные меню
- **Дерево проекта**: разворачивающиеся папки с тематическими SVG-иконками, навигация вверх по директориям, создание файлов и папок.
- **Контекстное меню проводника**: быстрое создание, открытие, переименование, удаление файлов и обновление директории.
- **Контекстное меню редактора**: стилизованное Catppuccin Mocha меню с операциями Undo, Redo, Cut, Copy, Paste, Select All и Comment.
- **Кэширование сессии**: запоминание последней открытой папки и файлов в `AppData/Local/ASMCode/session.json`.

### 5. Дизайн и нативная интеграция в Windows
- **Отсутствие консольного окна**: приложение собрано как нативный GUI-процесс Windows (`IMAGE_SUBSYSTEM_WINDOWS_GUI`).
- **Собственная иконка**: микропроцессор Intel 8080 вшит в заголовок PE-файла (`.rsrc`).
- **Тёмная тема Catppuccin Mocha**: тщательно выверенные контрастные цвета, соответствующие стандарту WCAG AA.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl + S` | Сохранить текущий файл на диск |
| `Ctrl + O` | Открыть файл через системный проводник |
| `Ctrl + Z` | Отменить последнее действие (Undo) |
| `Ctrl + Y` | Повторить отмененное действие (Redo) |
| `Ctrl + Пробел` | Вызвать всплывающие подсказки (Autocomplete) |
| `Ctrl + /` | Закомментировать / раскомментировать строку (`;`) |
| `Ctrl + Колесо мыши` | Масштабировать размер шрифта в редакторе |
| `Shift + F10` / `Menu` | Открыть контекстное меню редактора |
| `Escape` | Закрыть контекстное меню или окно подсказок |

## Сборка и запуск

### Системные требования
- **ОС**: Windows 10 / 11 (или Linux / macOS с установленным Slint бэкендом).
- **Rust**: компилятор Rust 1.75+ (edition 2021/2024).
- **Утилиты сборки (опционально для CP/M)**: `C:\bin\asmx20.exe` и `C:\bin\cpmemu.exe`.

### Команды сборки

Сборка и запуск в режиме разработки:
```powershell
cd D:\Rust\asmcode
cargo run
```

Запуск тестов валидатора, синтаксиса и извлечения меток:
```powershell
cargo test
```

Сборка релизного оптимизированного бинарного файла:
```powershell
cargo build --release
```
Готовый файл будет расположен по пути `target/release/asmcode.exe`.
