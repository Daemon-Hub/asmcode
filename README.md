# ASMCode: Intel 8080 IDE

ASMCode - это современная, высокопроизводительная и легковесная среда разработки (IDE) на языке Rust с декларативным графическим интерфейсом на базе фреймворка Slint. Приложение создано специально для написания, статического анализа, компиляции и эмуляции программ на ассемблере микропроцессора Intel 8080 и операционной системы CP/M.

---

## Ключевые возможности

### 1. Двухслойный редактор кода и точное выделение
- **Многоцветная подсветка синтаксиса**: индивидуальная цветовая гамма для мнемоник, регистров, директив, меток, констант, строк и комментариев без использования белого цвета в коде.
- **Подстрочное полукруглое выделение (стиль VS Code)**: фон выделения рисуется строго под глифами символов со скругленными краями, полностью сохраняя цветную подсветку текста.
- **Моноширинное позиционирование**: фиксированная сетка символов с поддержкой `CaskaydiaCove NF SemiBold`, исключающая смещение курсора между буквами.
- **Синхронизированный наклонный курсор**: плавное мигание с настраиваемой анимацией (включение/отключение) и адаптивной геометрией каретки.
- **История изменений**: надежный менеджер Undo/Redo (`Ctrl+Z` / `Ctrl+Y`) с защитой от случайного стирания буфера при посимвольном вводе.
- **Горячее комментирование**: быстрое переключение строчных комментариев `;` по нажатию `Ctrl+/`.

### 2. Панель вкладок (TabBar)
- **Многодокументный интерфейс**: вкладки открытых файлов расположены между проводником и правой панелью документации.
- **Горизонтальная прокрутка**: стилизованный скроллбар при переполнении панели, плавный скролл колесом мыши.
- **Индикаторы состояния**: подсветка активного файла, маркер несохраненных правок (`*`) и индивидуальная кнопка закрытия (`x`).
- **Закрепление вкладок (Pin)**: закрепленные вкладки защищены от закрытия при пакетных операциях.
- **Контекстное меню вкладок**:
  - Закрыть текущую вкладку (`Ctrl+W`).
  - Закрыть другие вкладки.
  - Закрыть сохраненные вкладки (`Ctrl+K U`).
  - Закрыть все вкладки (`Ctrl+K W`).
  - Скопировать путь / Скопировать относительный путь (`Shift+Alt+C`, `Ctrl+K Shift+C`).
  - Открыть в системном проводнике Windows (`Shift+Alt+R`).
  - Показать в панели проводника проекта.
  - Закрепить / Открепить вкладку (`Ctrl+K Enter`).

### 3. Двойной тулчейн сборки и эмуляции
- **1) По умолчанию (Встроенный pure-Rust движок)**:
  - Автономная сборка и запуск программ на базе крейта `intel-8080-kit`.
  - Генерация валидных исполняемых файлов CP/M `.COM` без внешних зависимостей.
  - Встроенная эмуляция микропроцессора Intel 8080 и системных вызовов CP/M BDOS (вывод символов, вывод строк `$`, системный сброс).
- **2) Путь к бинарнику (Внешние asmx20 + cpmemu)**:
  - Возможность указать путь к внешнему компилятору `asmx20.exe` и эмулятору `cpmemu.exe` через диалог выбора файлов («Обзор...»).
- **Автоматический откат с предупреждением**:
  - Если в режиме внешнего бинарника файл не найден или путь некорректен, IDE автоматически переключается на встроенный движок, выводя предупреждение в консоль и строку состояния.

### 4. Полноценное окно настроек (Файл > Настройки)
- Модальное центрированное окно с категориями настроек:
  - **Редактор кода**: размер шрифта (с шагом +/-), курсив для директив, анимация мигания курсора, ширина табуляции (2 или 4 пробела).
  - **Внешний вид**: выбор цветовой темы (Cyberpunk 2077 Red / Catppuccin Mocha), язык интерфейса (Русский RU / English EN).
  - **Большие файлы**: режим `largeFileOptimizations`, порог авто-оптимизации (МБ), порог предупреждения ОЗУ (МБ).
  - **Тулчейн (Сборка)**: переключение режима тулчейна (по умолчанию / внешний бинарник), выбор путей к `asmx20` и `cpmemu`.
- Кнопки «Сбросить по умолчанию», «Закрыть» и «Сохранить».
- Полная персистентность: все параметры автоматически сохраняются в `%LOCALAPPDATA%\ASMCode\session.json`.

### 5. Интеллектуальный справочник и автодополнение
- **Интерактивная энциклопедия Intel 8080**: 60 документированных инструкций процессора. Для каждой команды указаны синтаксис, флаги (Z, S, P, CY, AC), такты и размер в байтах.
- **Контекстные подсказки**: всплывающее окно автодополнения по `Ctrl+Пробел` с быстрым переходом по стрелкам `Up`/`Down` и вставкой по `Enter`/`Tab`.
- **Детектор меток (Labels Outline)**: автоматический парсинг меток и директив `EQU` в реальном времени с номерами строк и быстрой навигацией.

### 6. Проводник файлов и безопасное удаление
- **Дерево проекта**: разворачивающиеся папки с векторными SVG-иконками, создание файлов и папок.
- **Отмена удаления (Ctrl+Z в проводнике)**: случайное удаление файлов или папок можно мгновенно отменить.
- **Защита открытых вкладок**: предупреждающее модальное окно при удалении файла, открытого во вкладках.
- **Фиксированные контекстные меню**: контекстные окна появляются строго в точке клика мыши и не прокручиваются вместе с текстом.

## Темы оформления

Приложение поддерживает сквозную стилизацию всех элементов интерфейса (редактор, вкладки, сайдбар, терминал, модальные окна):
1. **Cyberpunk 2077 Red**: контрастная неоновая палитра в темно-бордовых, желтых, голубых и фиолетовых тонах с ярким акцентом.
2. **Catppuccin Mocha**: мягкая пастельная темная тема, соответствующая стандарту WCAG AA.

Быстрое переключение доступно через меню **Вид > Цветовая тема** (с выпадающим вправо подменю) либо через окно настроек.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl + S` | Сохранить текущий файл на диск |
| `Ctrl + O` | Открыть файл через системный проводник |
| `Ctrl + W` | Закрыть активную вкладку |
| `Ctrl + Z` | Отменить последнее действие (в редакторе или проводнике) |
| `Ctrl + Y` | Повторить отмененное действие (Redo) |
| `Ctrl + Пробел` | Вызвать всплывающие подсказки (Autocomplete) |
| `Ctrl + /` | Закомментировать / раскомментировать строку (`;`) |
| `Ctrl + Колесо мыши` | Масштабировать размер шрифта в редакторе |
| `Shift + F10` / `Menu` | Открыть контекстное меню редактора |
| `Escape` | Закрыть модальное окно, контекстное меню или подсказки |

## Сборка и тестирование

### Системные требования
- **ОС**: Windows 10 / 11, Linux или macOS.
- **Rust**: компилятор Rust 1.80+ (редакция 2024).

### Команды

Запуск IDE в режиме разработки:
```powershell
cargo run
```

Запуск полного набора из 21 модульного и интеграционного теста:
```powershell
cargo test
```

Проверка линтером Clippy:
```powershell
cargo clippy -- -D warnings
```

Сборка оптимизированного релизного исполняемого файла:
```powershell
cargo build --release
```
Готовый бинарник будет расположен по пути `target/release/asmcode.exe`.
